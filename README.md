
# 🚗 Drowsy Driver Detection System

## Overview
This project uses deep learning to detect whether a driver is drowsy or alert using facial images.

## Models
- Custom CNN
- ResNet-18 (transfer learning)

## Dataset
Driver Drowsiness Dataset (DDD) from Kaggle (~41k images)

## Results
- CNN Accuracy: ~99.97%
- ResNet-18 Accuracy: ~100%

## Tech Stack
Python, PyTorch, Machine Learning
